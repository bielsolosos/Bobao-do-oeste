# Marketplace Intelligence Web App ⚛️ / 🅰️ (TypeScript)

Interface de usuário (SPA) para visualização de métricas de BI, histórico de preços, alertas de oportunidade e disparo de coletas.

## 🎯 Responsabilidades
- Dashboards com gráficos de evolução de preços
- Listagem e busca avançada de hardware (ThinkPads, GPUs, Mini PCs)
- Gerenciamento de alertas de preço

## 🛠️ Tecnologias
- TypeScript
- Next.js / Angular / Vite + React
- Tailwind CSS
